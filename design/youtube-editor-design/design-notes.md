# 유튜브 편집기 화면 디자인 메모

편성표 앱(design/mockup.html)과 같은 디자인 언어. `mockup.html`이 원본이고 `screens/*.png`는 그 렌더링(2배 해상도). PySide6로 옮길 때 아래 값을 QSS/팔레트로 그대로 쓴다.

## 색
| 이름 | 값 | 용도 |
|---|---|---|
| bg | #E9EDF1 | 창 바탕 |
| surface | #FFFFFF | 카드, 패널 |
| surface-2 | #F5F7F9 | 표 머리, 플레이어 바 |
| line / line-soft | #D3DAE1 / #E6EAEE | 테두리, 구분선 |
| ink / ink-2 / ink-3 | #18212C / #4A5664 / #8793A0 | 글자 (진함→흐림), 사이드바 배경 = ink |
| talk / talk-tint | #1D6B73 / #D3EBEC | 남는 멘트 구간, 진행 막대 |
| music / music-tint | #B57A0A / #F5E4BE | 잘린 음악 구간 |
| tally | #D0342C | 재생 위치 선 (온에어 빨강) |
| ok | #2F7D4F | 완료 표시 |

## 글꼴
Pretendard Variable (OFL, 앱에 폰트 파일 포함). 대체: 맑은 고딕. 숫자는 고정폭 숫자(tnum).
크기: 화면 제목 20px/800, 결과 숫자 22px/800, 본문 13px, 보조 12px, 작은 라벨 11px/700.

## 크기·간격
창 기본 1280×800. 사이드바 148px, 결과 화면 오른쪽 패널 296px.
바깥 여백 22px, 카드 안 여백 14~16px, 카드 사이 14px.
모서리: 버튼·카드 8px, 작은 요소 4px, 배지 완전 둥글게.
표 행 높이 36px, 표 머리 30px. 파형 높이 120px, 구간 레인 24px.

## 화면 상태
1. 빈 화면: 파일 끌어다 놓기 영역 + 최근 작업 목록
2. 변환 중: 단계 4개(오디오 읽기 → 음악 구간 찾기 → 경계 다듬기 → 미리듣기 파일 만들기)와 진행률
3. 결과: 눈금자 + 곡 구간 레인 + 파형 + 남는 구간 막대, 플레이어(원본/결과 전환), 잘린 구간 목록(행 클릭 시 그 구간 재생), 오른쪽에 결과 요약·썸네일·저장 위치·고급 설정·영상 만들기

## 규칙
20초 미만 음악은 자르지 않고 점선 테두리로 "짧은 음악(남김)" 표시 → 사람이 듣고 확인.
눈금자는 1분마다 작은 눈금, 5분마다 숫자. 편성표 앱의 월 다이얼과 같은 모양.

## 아이콘
icon/app.svg (원본), app_256.png, app.ico (16~256px 포함). exe 아이콘과 설치 화면에 사용.
